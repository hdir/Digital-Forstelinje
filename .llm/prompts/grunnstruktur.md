## Input 

Given the skill for archimate modeling using drawio described in archimate-modelleringv2.

## Tasks

* Kan du lage en drawio side som inneholder de delene av helsetjenesten som nevnes i dokumentet tegnet som business-role.
* delene av helsetjenesten kan vises som business-role elementer med navnet til rollen i elementet
* Kan du også tegne inn relasjoner mellom de ulike boksene som beskriver de vanligste måtene pasienter beveger seg mellom de ulike delene av helsetjenesten på som er nevnt i dokumentet, bruk flow relasjonstypen

## Output

* Add the diagram as a separate page in the docs\business\prosess.drawio diagram file

## Avoid

* Crossing relationships
* Overlapping archimate elements
* Excessively long relationship lines
* Excessively big archimate element size
* keep the diagram as compact as possible without creating overlap
